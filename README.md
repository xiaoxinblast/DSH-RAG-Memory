# DSH-RAG-Memory

本地优先的 DSH 独立记忆插件。个人偏好与全局规则共享，项目事实按工作区路径隔离。首版只接管启用后到达的新文本对话，不扫描历史聊天，不读取或迁移喵记忆数据库。

## 当前状态

包版本 `0.1.4`，声明适配 DSH `0.2.1-rc.5`、Node.js `>=24.2`。选定路线为 **v7 写入内核＋DeepSeek Flash**，提炼与复核统一使用协议 `version=7`，一个纯裁决入口决定最终结果。生产内核沿用冻结版本，原文检索与轻量索引实验不接入。包版本、协议版本和历史评估轮次分别管理，不把历史 `kernel-v7` 标签当作协议版本。

选定方案是综合取舍，不代表模型已通过全部质量门槛。两阶段仍可能同时误判限定条件、临时指令或未知跨语言重述；来源引用与格式正确不等于语义正确。最终回归使用 176 项现有测试及真实 DSH SDK 本机合成回环，结果单独保存在 `.cache/final-v7/`，不会覆盖历史报告。详情见随包附带的 [v7 选型、运行与回退说明](docs/release-v7.md)。本次不新增付费测试，不处理真实聊天或升级日用环境。

## 使用方式

插件启用后，左侧“DSH-RAG-Memory”提供记忆库、处理队列、用量与费用、连接设置。记忆可以搜索、查看来源、纠正、确认候选或遗忘。点击卡片后，详情在右侧抽屉中打开，不挤压卡片网格或移动列表位置；抽屉正文独立滚动，关闭按钮保持可见，窄窗口使用全宽抽屉。对话中的召回显示为可展开记忆卡片，历史卡片在重启后可恢复。遗忘立即移出检索并清除向量；本地修订记录仍会保留，不代表物理擦除全部历史数据。

自动整理在 4 轮对话完成，或有未处理片段且会话空闲 2 分钟后运行。每次只处理新的片段，输入使用 UTF-8 字节数作为保守 Token 预算，提炼阶段上限 8000、复核阶段上限 16000。来源较长时按片段处理，不代表全文导入。助手自述不能独自支持已确认事实；工具报错可支持实际失败进展，不能据此记录成功完成。

后台自动写入和 Agent 工具的保存、更新、遗忘共用“提炼 → 独立复核 → 裁决 → 事务提交”链路；每批最多一次提炼、一次同模型复核，没有合法非跳过提议时不复核。普通项目新增也需要复核；全局、纠正、遗忘和重新记住另需明确用户授权。任一阶段判断未决或只存候选，另一阶段不得自动提升；事件处于计划阶段不代表该计划未经确认。坏项单独留下需要检查的凭证，其余合法项继续处理。不确定的写入保留候选，遗忘不确定时需要澄清，旧结论保留。暂停云端时 Agent 写入等待恢复；用户在管理界面的明确人工操作仍不调用模型。

遗忘同时清除条目向量、查询缓存及召回快照。后续输入会遮蔽已遗忘来源范围，旧批次失效，Agent 读取工具不返回已遗忘正文。用户明确重新记住时创建新条目，旧条目仍保持已遗忘；管理界面保留本地来源及修订审计。这不代表物理擦除原始历史或已经发送给模型的内容。

新会话首轮及每条用户消息进行一次召回，工具后续步骤复用快照；记忆变化后快照失效。当前项目与全局范围先过滤，再融合 SQLite FTS5 关键词、主体和本地向量候选，最多精排 8 条、注入 5 条。注入正文总预算不超过 1500，稳定全局核心先分配最多 400，其余优先保留当前任务相关记忆，闲置预算可以借用。实际 Token 数以模型用量为准。云端总等待上限 2 秒，超时回退本地检索。

正常召回排除待确认、已替代、已遗忘及来源明确过期的条目。工具搜索可选 `history: true` 查看已替代历史，或用 `at` 指定 ISO 时间；始终不返回已遗忘内容。不按记忆年龄自动删除事实、偏好或未完成计划。

记忆库界面的搜索框按记忆正文匹配，默认显示按更新时间倒序排列的使用中记忆，每次最多显示 200 条。这里的列表筛选与对话中的混合检索是两条独立流程；待确认、已替代和已遗忘的记忆不会被自动召回。

## 配置提炼模型与检索连接

在“连接设置 → DSH 提炼模型”选择 **DeepSeek Flash** 并保存。已实测路由为 `deepseek-account / deepseek-flash`；提供商 ID 取决于你的 DSH 配置，插件不创建账户或读取别的插件凭据。不修改主聊天模型，也不随主聊天模型变化。新安装没有选定路由时保留队列，已有配置保持原值；这次打包不会自动替你切换。

以下 Qwen 连接只用于向量和精排，与 DeepSeek 提炼分别配置：

1. 打开 [阿里云百炼控制台](https://bailian.console.aliyun.com/)，选择华北 2（北京）。
2. 按 [API Key 官方说明](https://help.aliyun.com/zh/model-studio/get-api-key)开通服务并创建 Key。
3. 取得同一业务空间的 [Workspace ID](https://help.aliyun.cn/zh/model-studio/obtain-the-app-id-and-workspace-id)。
4. 在插件“连接设置”填入 Workspace ID；“API Key 保存名称”保留默认 `DSH_MEMORY_API_KEY`。它是 DSH 保存和读取 Key 时使用的名称（凭据引用），只接受大写字母、数字和下划线，不能以数字开头；留空保存会恢复默认值，请勿填写网址。Key 只填写到密码框，点击“保存连接”。随后点击“测试连接”（会产生少量模型费用）；进行中、成功或失败的反馈显示在按钮下方。API Key 留空时沿用此名称下已有的 Key。

提炼通过 DSH 原生 `ctx.llm.prepareCall/stream`，使用插件设置中单独选定的 DSH 提供商、模型与其凭据；独立发送受长度限制的新片段，不附带主聊天历史和工具。在“连接设置 → DSH 提炼模型”中选择并保存，不跟随聊天模型；未选择或模型不可用时保留队列，不自动回退到其他模型。默认向量 `text-embedding-v4`（1024 维）、精排 `qwen3-rerank`。Endpoint 由 Workspace ID 和固定北京地域域名拼接，禁止重定向凭据到其他主机。

Key 由 `ctx.credentials` 保存；普通设置与数据库不保存 Key。凭据服务不能提供针对同一操作系统用户的绝对隔离。发送前会遮蔽常见凭据格式，但不应主动要求记忆保存任何密码、验证码或密钥。

## 存储和费用

数据库：`$DSH_HOME/storages/dsh-memory/memory.sqlite`。与源码、DSH 程序目录、旧 `.dsh-meow` 分开。冻结 v7 使用数据库 schema 3；本次收尾不新增表、列或迁移，协议语义存入现有阶段和凭证 JSON。旧 ID、正文、来源及修订保留，不补造语义字段或批量重提炼。旧协议未完成任务保留为需要检查，不重新解释或重新付费处理。更早安装首次升级仍可能执行已有的 schema 迁移，须先备份；不要让旧插件继续执行新协议任务。详见 [兼容与回退说明](docs/release-v7.md)。

后台使用两分钟租约、执行令牌和每 30 秒续租。原始回答和用量先保存，再解析；已收到的坏 JSON 与请求结果不明分别记录。已保存回答后的事务失败只重放本地处理，结果不明不自动重发；所有项的决定或错误凭证提交后才推进检查点。处理队列保留候选、拒绝、澄清和需要检查的原因，DSH 用量按提炼／独立复核分列。

Qwen 向量和精排的每月提醒目标默认 10 元（香港时区自然月），达到后继续运行。费用按固定模型标价估算：[官方模型价格](https://help.aliyun.com/zh/model-studio/model-pricing)，2026-11-02 核查。向量和精排各为 0.5 元/百万输入 Token。DSH 提炼另记 provider/model、输入输出 Token 和本地请求审计，不编造主模型单价；其费用不计入 Qwen 提醒金额。精排预算包括查询文本随候选重复计入的部分。响应缺失 `usage` 或超时时保留估算标记，真实账单以百炼为准。免费额度不纳入价格估算。

主模型新增上下文单独计数。本页统计新注入的保守预算，不能精确反映后续上下文重放、缓存折扣和不同主模型的全部账单。

## 开发与验证

```powershell
npm install
npm run build
npm test
npm run test:ui
npm run test:library-ui
npm run check
npm run evaluate
```

开发环境需要同版本的 DSH peer 包。可使用 DSH 源码/SDK的 `node_modules`；不要复制旧插件数据到测试目录。若复用已有开发依赖，设置 `DSH_DEV_MODULES` 为包含 `esbuild`、`@playwright/test`、`react` 和 `react-dom` 的 `node_modules` 绝对路径。

`npm run test:ui` 使用无界面 Edge 渲染实际设置组件和内存数据库，验证独立保存、凭据名称校验、未保存配置提示、测试进行中及成功/失败反馈，并生成明暗主题和不同宽度的截图至 `.cache/settings-ui/`。它只使用合成凭据和模拟响应，不访问真实模型服务。

`npm run test:library-ui` 使用 40 条合成记忆验证底部点击、网格与滚动位置保持、详情独立滚动、连续切换、纠正保存、Escape 关闭及焦点返回，并将不同宽度和明暗主题的截图保存至 `.cache/library-ui/`。它不读取真实记忆或调用模型服务。

`npm test` 执行构建、源码检查及当前完整离线套件，外网防护只允许本机回环；报告写入 `.cache/final-v7/verification/`。不要用历史 `verify-kernel.mjs` 重新生成已冻结证据。

`npm run evaluate` 只执行固定的 60 例本地关键词基线，不代表提炼语义质量。历史付费评估脚本和 `experiments/` 留作证据，不进入默认回归或发布包，不再扩展原文／索引方案。本轮不运行任何 `--live` 评估。

隔离 Host 使用 `.cache/home`，仅在该隔离环境运行 `scripts/seed-demo.mjs`。启动后运行 `node scripts/verify-ui.mjs "<完整回环URL>"` 检查实际操作、明暗主题、1180/768/390 像素容器布局与截图。验收报告保存在 `.cache/`，不进入发布包。

## 安装与日用切换

本次只交付本地安装包，日用配置保持原状。源码构建及最终回归通过后运行 `npm pack --offline --ignore-scripts` 得到本地包；包内不包含数据库、凭据、测试浏览器资料、实验、历史评估原始回答和 `.cache`。安装包的交付不等于已部署或模型已达到全部语义门槛。

插件显示名称为 `DSH-RAG-Memory`，安装包名为 `dsh-rag-memory`。从旧包 `dsh-memory` 切换时，先停用旧包，再安装并启用新包，避免两份插件同时运行。原有 `$DSH_HOME/storages/dsh-memory/memory.sqlite`、`DSH_MEMORY_API_KEY` 凭据名称及 `dsh_memory_*` 工具接口继续沿用，无须搬移记忆数据。

通过验收后，完全退出 DSH（包含托盘进程），备份日用 profile 的 `package.json`、`pnpm-lock.yaml`、`cordis.patch.yml` 和所有旧记忆库。SQLite 应使用一致性备份并检查完整性，不直接复制正在写入的主文件。

使用 DSH 官方插件管理器安装本地包并先保持停用，随后停用 `meow-memory` 组合包、启用 `dsh-rag-memory`，重启检查。两套插件不要同时自动记录和注入。不要卸载或删除旧插件及其数据。

需要回退时退出 DSH，恢复 profile 备份或停用 `dsh-rag-memory`、重新启用 `meow-memory`，然后重启。新记忆库保留在自己的存储目录，不覆盖旧库。
