- 安装包：`dsh-rag-memory@0.1.4`；界面显示 `DSH-RAG-Memory`。

- 声明宿主：DSH `0.2.1-rc.5`；Node.js `>=24.2`。其他宿主版本不作为本次已验证范围。
- 采集新文本 → 有来源的提议 → 独立复核 → 单一裁决 → 版本/范围/遗忘校验及事务提交。
- 每批最多一次提炼、一次复核；无合法非跳过提议不复核。最终单元保留必要条件，坏项隔离，候选不自动升级。
- 关键词、向量、主体检索、注入预算、来源审计、租约、恢复及人工操作沿用冻结实现。本次收尾没有再次改写内核；UI 仅同步侧栏包版本号，布局与交互不变。

## 模型配置

已实测提炼路由为 `deepseek-account / deepseek-flash`，提炼和独立复核使用同一选定路由。提供商 ID 由 DSH 的实际账户配置决定，不要求所有安装都使用同一个 ID。

在插件“连接设置 → DSH 提炼模型”选择 DeepSeek Flash 并保存。新安装保持未配置状态，已有路由保持原值；模型未选择或不可用时队列等待，不自动回退或选择其他模型。主聊天模型不受影响。本次交付没有执行这一步。

请求使用 `temperature=0`、输出上限 2,048、90 秒超时。适配器按模型可用控件选择最低推理档；此前真实测试核对了当时 DeepSeek 请求的非思考设置，不把“最低档”当成所有供应商永久支持关闭思考的保证。提炼不附带主聊天历史与工具。供应商账户与凭据仍由 DSH 管理。

Qwen 仅继续用于现有向量 `text-embedding-v4`（1024 维）及精排 `qwen3-rerank`，与提炼模型分开配置。不新增供应商或运行依赖。

## 已知效果与限制

2026-11-03 冻结 v7 的合成测试中，DeepSeek 的新有效记忆精确率为 50/54（92.59%），应记内容覆盖率为 63/80（78.75%），两阶段首次完整结构通过率为 93/96（96.88%），明确遗忘执行为 8/8。属于 48 个案例各两遍，不是长期质量保证或新一轮实测。

仍存在必要条件被拆到不同条目、临时指令误入库、协议字段输出错误，以及未知跨语言重述绕过语义识别的风险。两个模型阶段可能一致犯错；真实来源、合法 JSON 和复核通过均不能单独证明事实正确。

遗忘立即停止召回并清除相关向量、缓存和快照，保留本地来源、修订和审计。它不是物理擦除，也不能撤回已经发送给模型的内容。未知跨语言等义识别未被证明完善。

本地回归、模拟 SDK 回环和打包验证只能证明程序及确定性约束的执行。历史模型回答与实验评分不因本次打包而改变。
