单项隔离仅针对提炼响应中的操作格式与原文引用错误。原始 JSON 无法解析、顶层版本/字段不合法、超过批次上限等仍中止；基础设施错误仍走既有可恢复路径。没有自动把非法 `intent` 改成合法值，没有把漏填的 target 字段默认为授权，也没有增加额外付费修复请求。

所有语法不合法的项单独留下拒绝凭证，合法项按既有语义、范围、候选、版本和遗忘策略继续处理。若全部项都无效，可在持久化拒绝决定后完成该批来源；原始模型回答仍保留在提炼审计中。有效阶段结果已持久化、但事务失败时，复用同一结果重放本地事务。

未决、因果和完成检查是有限中文模式及动作层级检查，不是通用事实证明器。它们不能独立证明复杂句中同一动作的不同主体、同义表达或多重否定的全部关系；仍保留独立复核。对完整正确表述是否存在误拦截，必须看本轮合成复测，不能只看错误拦截数量。
