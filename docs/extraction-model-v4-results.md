**三者仍未全部达标，不切换日用模型。** 原文编号引用、明确仅候选授权、唯一遗忘及混合遗忘的专项结果改善明显。DeepSeek 在本组合成集的最终有效记忆精确率和信息召回最高，但仍有无效持久规则和限定拆散，未达到 98% 精确率。Flash 最便宜；27B 本轮没有证明其额外费用带来更好整体质量。

## 本轮修复与验证

- 模型改为引用宿主生成的原文片段编号；宿主严格解析成 UTF-16 范围。非法编号、手填偏移、遮蔽片段一律拒绝。复核使用绑定实际范围的独立编号，数字越界不再交给模型修正。
- 明确“只存候选、暂不生效”成为宿主授权上限；复核批准不能把它激活。检查完整关联用户消息，不能通过省略授权句绕过。引文、助手消息和否定候选句不冒充该限制。
- 精简 forget/skip 结构；遗忘目标与版本仍严格核对。区分原始用户记忆授权、第三方引文和越权指令；“删除功能验收”不再被宽泛遗忘词匹配吞掉。混合消息分别处理遗忘和新事实。
- 先复现失败，再通过完整离线回归 **152/152**，包含真实 DSH SDK 两阶段回环；随后冻结生产代码和合成数据，再发付费请求。额外评分器锚点回归 **1/1**；源码检查与构建通过。构建使用现有 `DSH_DEV_MODULES` 依赖目录，没有安装依赖。本轮没有 UI 改动。
- 模型传输协议为 v4，内部规范操作及数据库继续使用既有 v3；本轮没有数据库迁移。历史报告、历史原始回答和 43 文件基线备份均保留。

## 三项修复的真实结果及剩余问题

1. **原文引用：**全部 669 项提议（包含 skip/forget）的编号均可解析为合法原文范围；其中写提议 457/457。所有 112 次复核结构有效。范围合法不等于语义引用充分，例如跨消息事实仍可能只引用其中一条；这不计作“模型语义已通过”。
2. **明确候选：**4 个案例×3 模型×2 遍，共 24 次均未擅自激活；21 次成功保留候选，3 次遗漏（27B 两次、DeepSeek 一次，分别包含格式失败或复核过度拒绝）。Flash 另有一次“先改它，但还没确定哪个”的歧义计划被激活：这不是明确仅候选语句，仍计高影响错误，不能声称所有待确认授权都解决了。
3. **遗忘：**唯一遗忘 12/12 正确；“忘掉 A，同时记录 B”12/12 完成两部分；目标模糊 12/12 保持旧状态并产生澄清；否定或引用遗忘 18/18 未删旧条目。明确重新记住 12/12 建立新记录，原 forgotten 条目保持遗忘。所有案例的旧条目状态与金标一致，未观察到跨项目修改或旧遗忘条目复活。Flash 在否定遗忘案例额外保存了指令本身，两次均计内容错误。
4. **普通新增仍有质量缺口：**“记住权限边界”“不能写成切换成功”等操作／表达要求被单独持久保存；端口与访问限制被拆开；未解析指代也可能入库。DeepSeek 还有一次将“不能认定 SQLite 导致故障”写成“SQLite 导致故障的原因尚未查明”，引入原文不支持的因果预设。原文编号能解决位置可靠性，不能替代独立条目的完整性判断。
5. **格式仍有 7 次失败：**千问各 3 次，DeepSeek 1 次，涉及非法 intent 或 global 类型组合；本轮未容错改写回答。全局仅候选仍调用复核，模型可能误把“保存候选”理解为“立即激活”而拒绝，导致遗漏。

上述分母仅代表本次有限合成样本，零错误不解释为长期安全保证。长对话、复杂混合授权、更多自然语言变体和网络异常的真实模型效果仍未验证。

## 建议与交付边界

保持现用 DeepSeek；本轮结果支持继续以它作为对照，不支持切换到 Flash 或 27B。后续优先修普通新增的持久价值、指代完整性和跨片段限定合并，再处理“保存候选”和“立即激活”的复核语义，以及歧义计划必须待确认的规则。当前冻结版本保留原样，未用本轮新验收案例修改生产逻辑或重新付费刷分。

只发送合成数据，每任务独立内存库；准备旧记忆只走本地检索，无付费向量或精排。只读日用库 settings 行确认路线，没有读取真实聊天，没有升级日用数据库、安装或切换模型；配置、凭据与 profile 前后指纹一致。没有提交或推送。

本轮实现、兼容与回退说明见 [memory-logic-v4.md](memory-logic-v4.md)。机器报告 [extraction-model-v4-results.json](extraction-model-v4-results.json) 包含错误正文、理由、分组、费用、指纹；原始回答、阶段日志与复核依据在 `.cache/extraction-evaluation/v4/`。离线重算：`node scripts/score-extraction-v4.mjs score`、`node scripts/report-extraction-v4.mjs`，两者不调用模型。`run-extraction-v4.mjs` 为付费采集入口，本清单已完整完成，不需要再次运行。
