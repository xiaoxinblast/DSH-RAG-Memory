# 无价值指令、限定条件、歧义计划与候选处理

日期：2026-11-03。本轮在现有 v4 原文锚点和遗忘策略之上实现内容策略 v5，先通过离线回归，再冻结生产源码、合成案例和参数进行三模型复测。没有部署到日用 DSH。真实模型的效果及仍未解决的失败样本以 [v5 复测报告](extraction-model-v5-results.md) 为准；离线通过不表示所有自然语言表达都已处理正确。

## 代码与行为

| 文件 | 改动 | 对应验证 |
|---|---|---|
| `src/content-policy.mjs` | 检查纯记忆指令、未解析指代、跨消息限定依赖及明确未决计划；输出拒绝原因、内容复核要求或待确认上限 | 无价值指令不单独入库；完整限定不能只引用前半句；未决计划不能因复核 approve 激活 |
| `src/policy.mjs` | 接入上述检查；明确只存候选时不再仅因全局范围要求激活授权复核，仍保留内容与来源检查 | 单纯保存候选不被错误的激活授权拒绝；事实性拒绝不被绕过 |
| `src/operations.mjs` | 在同一个第二阶段传递 `allowedState`、`reviewPurpose` 和 `checks`；复核后重新应用宿主状态上限 | 内容复核通过仍只能保存 pending；已有冲突、候选授权和证据上限不能被模型提升 |
| `src/extraction.mjs` | 提示词要求抽取事实而非“记住”命令，解析指代、合并必要限定并引用所有关联句段；复核区分候选内容与立即生效授权 | 不把候选待确认视为内容错误；不因结构合法而忽略条件、否定或因果支持 |

简单、有来源支持的普通事实仍可直接写入。包含条件、否定、因果或跨消息组合的内容进入独立复核；同一批所有需检查项合并为一个请求，没有增加第三次模型调用。高影响操作继续使用现有提炼型号做独立复核。

跨消息依赖只识别有限模式：相邻用户片段以指代开头且带有限定时，需要同时引用相关片段。缺少关联引用时保留候选，不能由宿主猜测补齐引用。候选的正文仍需独立可用；把限制另存为另一条，并不保证召回时能一同出现。

明确未决对象或优先顺序由宿主限制为待确认；明确“已决定下周执行、尚未完成”的计划仍允许保存为已确认计划。当前中文匹配并不覆盖所有同义表达，不能当作完整自然语言授权解析器；模型复测中的反例保留在报告中。

遗忘、墓碑、版本事务、旧状态保护与原文锚点沿用 v4。工具名称、必填参数、SQLite schema、原记忆 ID 与数据目录均未在本轮变动；未新增物理擦除或自动恢复旧遗忘记录的路径。
