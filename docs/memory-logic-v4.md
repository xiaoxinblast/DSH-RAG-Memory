| `src/policy.mjs` | 统一引用边界，识别完整来源的候选限制，遗忘授权排除引文与否定，缩小删除词匹配 | 裁掉候选授权句不能越权；删除功能验收可以保存；引文遗忘不删目标 |
| `src/operations.mjs` | 在复核决定之后再次应用候选授权上限，复核不得提升为 active | 即使模拟错误 approve，明确仅候选仍为 pending；遗忘只产生澄清 |

候选限制是针对明确表达的宿主约束，当前按关联来源消息识别，必要时保守地限制同消息内容。尚未证明可以精细区分一条复杂消息里“A 只存候选、B 立即生效”的所有组合；不要将这套文本规则当成完整自然语言授权解析器。真实复测还发现歧义计划和候选遗漏，均列入报告，没有隐藏或在测试后改协议刷分。

所有可见来源句段按顺序给出；遮蔽范围和凭据片段不提供锚点。锚点精确对应宿主原文，不要求模型数字符，也不允许自动夹紧越界值。模型仍有责任选全相关片段并保留限定；编号有效不代表推论正确。

遗忘继续沿用既有事务、版本校验、墓碑、向量清除和缓存失效机制，本轮没有另建删除路径。明确唯一遗忘须通过第二阶段；模糊目标保留原记忆并产生澄清。混合消息的遗忘和新事实使用各自引用，不能整条丢弃。
